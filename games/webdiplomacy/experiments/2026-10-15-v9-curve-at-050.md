# v9 (keep every phase start, budget curve) against v5 at a $0.50 cap

## Context

Built by the "Spend per game" thread on branch `claude/project-thread-9j4kxi` at 0fdcf57 (code 18a2d77), with
`CAPTURE_REVIEW=0.67,PRESS_UPDATE_BRIEFINGS=1,GOVERNOR_KEEP_STARTS=1,GOVERNOR_RESERVE_USD=0.02` on the clean
player base, and uploaded by the release thread as `scott-pidip:v8` (2fba209d-fdff-4988-a6fb-e448cfddf631). Scott
asked for a budget that follows a curve over the game and to "error on the side of under-squeezing where
possible". In one local game to 1908 at a $0.50 cap against six Luna seats, v8 spent $0.474, completed 16 of 16
phase starts on Sol, ran 17 press wakes and held back 12, with 0 refused calls and 0 rejected orders; v5 with no
governor in the same setup had every call refused from turn 9.

Earlier record `2026-10-14-v6-luna-press-at-050.md` (inconclusive, -0.052 ± 0.043 for v6): v5 was refused by
the cap from turn 7 in all 49 seats and still scored above v6. That is a prior that late-game model use is
worth less in this field than expected. Checked `closed_levers.md` (empty) and `open_levers.md` (the v6 entry).

v8's health game (`xreq_759cf260`, all seven seats v8, to 1908, $0.50 a seat, 05:01Z to 05:21Z, read by that
thread): 0 rejected orders, no 429s, $0.24 to $0.48 a seat; 35 of 817 calls got the sidecar's 502 "LLM sidecar
internal error" (the same 502 hit both arms of the v7 run from 04:34Z, so it is the platform's). It found one
governor bug: a phase start that failed on a 502 cost about $0 and still set the cost-curve scale, so one seat's
scale fell to 0.65 and it lost its two 1908 starts. Fixed in 7f8ef17 (only completed starts set the scale) and
uploaded by the release thread as `scott-pidip:v9` (e450bef4-4327-47da-bfd8-e7f7a1180caa) from 1080370, same
overrides. This record tests v9; v8 is not tested.

## Predictions — pre-registered

- **If TRUE we expect:** v9 minus v5 at least +0.03 a game, with v9 completing its phase starts through 1908
  (`wake` lines of kind phase_start every movement phase) and v5 refused from mid-game as in the v6 run.
- **If FALSE we expect:** a difference within ±0.03, or v9 below v5. That would say again that v5's lost
  late-game model calls cost it little in this field.

## Design

Paired, balanced (`run_ab.py`, 14 bodies x 5 = 70 games), field set `league-top5-2026-10-14`, every seat capped
at $0.50. Five a body because the v6 run lost 9 of 56 games to platform pod failures. Read beside the score:
phase starts completed per seat, seat spend (at or below $0.48), `wake_skipped` with reason `start_reserve`,
and refused calls. Launch after the v7 run (`2026-10-15-hybrid-diplodocus-vs-v5`) is read.

## Result

Read 06:50Z on 2026-10-15, all 14 batches terminal (`paired.py`, `wd.py metrics`, `wd.py costs`).

- **Paired:** v9 minus v5 **+0.051 ± 0.047 a game, z 1.09, n = 61 clean pairs** (paired SD 0.367; 7 games
  dropped, all `pod_deleted`). At 54 pairs (read 06:18Z) it was +0.076 ± 0.052.
- **Alone:** v9 0.279 a game (+0.156 ± 0.029 over field par, n = 64), 7.64 final centres; v5 0.222 (+0.090),
  6.79 centres.
- **Telemetry (v9):** 0 rejected orders, 0 exceptions; 537 of 9,276 model calls failed (5.8%), platform 502s.
  v5: 3,406 of 10,807 failed (31.5%), mostly refusals at the cap.
- **Spend:** v9 $0.462 a seat on average, max $0.485, none over $0.50. v5 $0.496, 59 of 62 seats over $0.50 by its
  own count (refused at the cap).

least 1, but |z| < 2. Failed calls are 5.8% against the bar's 1%, all platform 502s (v5's games had them too).
